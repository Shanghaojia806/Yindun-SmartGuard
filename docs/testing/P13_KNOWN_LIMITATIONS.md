# 银盾智鉴 · P13 已知限制

> 文档编号：P13-KNOWN-LIMITATIONS
> 日期：2026-11-20
> 原则：以下限制均来自当前代码与实测结果，未做推测性补全。

## 1. 端侧与 Android

1. **无原生 Android 真机测试记录。** 既有设备为华为 Mate 60 Pro / HarmonyOS 7.0.0.111，通过卓易通运行 APK，只能标记为 HarmonyOS 兼容环境测试。
2. MediaProjection 授权、前台服务通知、系统撤销、资源释放在本轮未重新上机验证。
3. P04 守护为 `FakeGuardService`，不采集屏幕、不录音、不做推理；P05 仅采集 PoC，无 OCR / 风险识别。
4. 老人端 E10 反诈知识、E11 情景测试、E15 反馈帮助未实现；E09 仅有 TTS 播报，无语音问答。
5. 家属端 F01–F12 数据全部来自本地 Fake 仓库，**不存在两台手机之间的远程同步**；F10 未实现。
6. 无真实账号、登录、会话与家属绑定服务。
7. 未测量采集状态下的 CPU、内存、发热、耗电与实际帧率稳定性；仅确认代码限制 5 FPS、`maxImages=2`、逐帧 `close()`。
8. 未做老人真实用户可用性测试（字体缩放、触控区域、提示理解度）。

## 2. 管理端

1. 登录页为本地模拟登录，不校验凭据；角色固定为“系统管理员（模拟）”，**不构成真实 RBAC**。
2. A01 工作台、A02 用户、A03 设备为 Mock 数据；A07 规则、A08 知识库、A09 风险反馈为占位页。
3. A04 数据集页面仍以 Mock 业务数据为主；后端只提供数据集快照登记、资格与训练检查接口，没有 `/admin/datasets` 列表 / 详情 / 标注 / 质检 API。
4. 模型版本数据集卡片已改为真实模式读取 `dataset-snapshot`；若后端无快照，会显示不可用，不再回退 Mock。
5. `index` 包 1,092.34 kB（gzip 360.43 kB），`TrainingDetailView` 547.07 kB，首屏与训练详情仍有体积优化空间。
6. 未做浏览器兼容性矩阵与无障碍（键盘 / 读屏）验收。

## 3. 后端与数据

1. `P11R_ADMIN_TOKEN` 为空时管理接口不鉴权；共享环境必须配置。
2. Worker Token 示例默认值为 `dev-worker-token-change-me`，生产必须替换。
3. 无 Alembic / 版本化迁移，仅启动时 `create_all()`；表结构升级无法平滑迁移。
4. 无备份、恢复、归档演练；SQLite 仅适合单机开发。
5. 无真实用户、设备、规则、知识库、反馈业务表与接口。
6. 角色权限由客户端 `roleLabel` 传入，服务端只做字符串比对，不是可信身份。
7. 训练任务未做业务级重复提交去重；模型导入按 `trainingTaskId` 幂等。
8. 未实现队列、分布式调度与 GPU 资源管理。

## 4. 训练与模型

1. 仅验证 CPU Smoke Test（合成数据、3 epoch），**不代表任何反诈识别能力**。
2. 无真实反诈数据集、真实测试集评估报告、模型卡与偏差评估。
3. 无生产 Ed25519 密钥、密钥轮换与吊销流程；当前为开发密钥 `development`。
4. 无 ONNX / TFLite 导出与端侧推理验证；`ml/export` 目录不存在。
5. 无真实设备兼容性测试记录，正式渠道始终被阻断。
6. 模型发布门槛未被降低；因此当前没有任何可灰度 / 正式发布的模型。
