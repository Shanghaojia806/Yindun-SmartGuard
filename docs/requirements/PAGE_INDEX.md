## 0. 阅读说明

### 1.2 老人端关键交互链路（V1.3 第 3.3 节）


### 2.1 家属端关键交互链路（V1.3 第 3.3 节）

```
有效绑定 + 共享授权 → 收到事件 → 查看摘要 F06 → 联系老人 F07 → 更新协同状态 → 老人查看反馈
```

### 2.2 协同状态枚举（V1.3 提示词 08）

`待查看` → `已查看` → `已联系` → `核实中` → `已协助处理` / `无法核实`

处理状态与 AI 原始风险等级**分别管理**；家属不能改写模型原始结论。

### 2.3 家属端硬性约束

- 仅显示授权共享事件；无授权时为空态，不得用模拟数据填充。
- 需要保留离线与消息延迟的展示状态。
- 界面须说明家属不能查看原始视频和实时屏幕。

### 3.2 管理端状态要求

- 每页包含 Loading / Empty / Error 三态（提示词 09），取数页补齐 Success。
- 训练任务状态：`pending / running / succeeded / failed / canceled`。
- 数据集：没有许可信息的样本不能标记为"可正式训练"。
- 训练与模型不得用模拟值伪装真实；未接真实 Worker 时只显示"模拟任务"。

## 4. 全局页面状态矩阵

每个取数页面必须实现四态：

| 状态 | 要求 |
|---|---|
| Loading | 骨架屏或明确加载提示，禁止无反馈白屏 |
| Success | 正常内容 |
| Empty | 说明"为什么空"与下一步操作 |
| Error | 可重试，显示可理解的错误原因 |

守护模块额外六态（V1.3 第 3.2 节）：未开启、授权中、运行中、降级运行、已停止、授权失效。

弱网要求：保持老人端本地守护能力。
